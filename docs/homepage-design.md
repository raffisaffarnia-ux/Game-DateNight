# DateNight homepage design

Direction: Taste `borrowed-category`, seed 171026. Borrowed world: a games-night poster. Apple Design was explicitly excluded by the user.

Inventory: private rooms, exactly two partners, distance between screens, create/join invitations, the existing nine-game registry, cooperative challenges, conversation games, Snake, drawing, pixel profiles, coins.

Idea: DateNight's private evening for two becomes the headline and programme of a games poster. Live interaction: three mood choices show real games from the existing registry.

Argument and copy:
- A shared evening starts here: “Heute: wir zwei”, supported by a direct create/join action.
- There is a game for your mood: “Worauf habt ihr Lust?”, backed by four linked covers from the product's actual game library.
- Privacy: “Euer Raum bleibt privat”.

Design system: Barlow Condensed for the headline; Barlow for copy. Post red, bone, mustard, slate and maroon from the dealt palette. Dark mode uses charcoal with light neutral ink. Local styles are scoped to the homepage. Covers retain the existing product artwork; there are no invented game screens or stock photographs. A video would add download cost without explaining these games, so the real interface previews provide the imagery instead.

The full direction generator initially stalled because it could not write its working folder. Re-running with a temporary output directory produced the sheet. No direction redraws. The showcase composition was adapted to the actual four game recommendations rather than inventing a two-product comparison.

Review: poster headline is the focal point; consistent edges and decisive type scale; four real product previews; mobile has its own two-column composition. Top fixes: remove the previous invitation styles, apply the dealt type and palette, and unify header typography. Self-assessment: design 8, usability 9, creativity 7, content 8; weighted 8.1/10. The catalogue art remains simple and could benefit from a separate future artwork commission.

Validation: Taste source lint; browser inspection at 1440/768/390; Playwright mood selection and create/join navigation; light/dark and reduced-motion checks. No game rules, room membership or shared state were changed.
